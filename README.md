# 195 國旗世界盃大逃殺 (195 Flags World Championship) - 直式直播系統

這是一個以國旗為單位的即時競賽畫面，適合透過 OBS 以 1080×1920 直式格式推送到 YouTube。觀眾可以用免費指令支援隊伍，或用 Super Chat 觸發有限度的戰術效果。

## 快速啟動指南

### 1. 啟動本機伺服器
```bash
npm start
```

### 2. OBS Studio 直式推流設定 (1080 x 1920)
1. 進入 OBS「設定」➜「影像」：
   - **基礎 (畫布) 解析度**：設為 `1080x1920`
   - **輸出 (縮放) 解析度**：設為 `1080x1920`
2. 在「來源」新增 **「瀏覽器」 (Browser)**：
   - **URL**：`http://localhost:3000`
   - **寬度**：`1080`
   - **高度**：`1920`
   - **影格率**：`60`
   - 勾選「場景變為可見時重新整理快取」
   - 取消勾選「在不可見時停用」

### 3. 綁定直播與測試
- 打開瀏覽器訪問 `http://localhost:3000/admin.html`。
- 輸入 YouTube 直播 ID 綁定聊天室監聽。正式直播時，觀眾留言會透過 WebSocket 即時傳到畫面；管理員控制台只用於必要的人工控制與故障排查。
